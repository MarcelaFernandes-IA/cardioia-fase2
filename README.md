## 📁 Estrutura da entrega

### 1. `cardioia-fase2` — Diagnóstico Automatizado
Uso de NLP e Machine Learning para identificação de sintomas, associação com possíveis diagnósticos e classificação de relatos em alto ou baixo risco. A pasta contém os arquivos de dados, notebooks e README específico.

### 2. `cardioia-portal` — Ir Além 1
Portal CardioIA desenvolvido em React + Vite, com autenticação simulada, pacientes, agendamentos, dashboard, Context API e proteção de rotas.

### 3. `cardioia-ecg-mlp` — Ir Além 2
Projeto de classificação de ECG com rede neural MLP. A pasta contém notebook, requisitos e README específico.

Os projetos foram desenvolvidos exclusivamente para fins acadêmicos. Os resultados e modelos não devem ser utilizados como substitutos de avaliação ou diagnóstico médico profissional.
